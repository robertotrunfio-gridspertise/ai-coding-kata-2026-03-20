**What I Would Not Add Before Refactoring**
To keep the safety net minimal-but-effective, I would not add these yet:

1. combinatorial exhaustive tests
   - too much cost, too little extra protection if the branch boundaries are already covered

2. property-based tests
   - useful later, but not the first safety net for legacy code

3. tests for impossible discount `> 40`
   - current code does not appear to make that branch reachable
   - forcing it would distort the existing behavior model
